# net-speed-meter

Скрипт замеряет скорость интернета со своего компьютера: делает 10 последовательных загрузок тяжелого файла, дожидается полного ответа, считает среднее время загрузки, объем скачанных данных и печатает скорость в МБ/с.

Только стандартная библиотека Python, зависимостей нет.

## Требования

Python 3.10+

## Запуск

```bash
git clone https://github.com/Baho73/net-speed-meter.git
cd net-speed-meter
python speedmeter.py https://proof.ovh.net/files/10Mb.dat
```

Подойдет любой тяжелый файл: большая картинка, архив, тестовый файл провайдера. Лучше брать файл, который качается несколько секунд: на мелком файле время съедают DNS, TLS-рукопожатие и задержка сервера.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `url` | обязательный | адрес файла, только http или https |
| `-n`, `--requests` | 10 | сколько загрузок сделать |
| `-t`, `--timeout` | 30 | таймаут сетевой операции, секунд |

Пример вывода:

```
# 1:  1.472 с,   10.49 МБ,    7.12 МБ/с
...
#10:  1.401 с,   10.49 МБ,    7.48 МБ/с
--------------------------------------------
Успешных загрузок: 10 из 10
Среднее время загрузки: 1.458 с
Скачано всего: 104.86 МБ
Средняя скорость: 7.19 МБ/с (57.5 Мбит/с)
```

Код возврата: 0, если прошли все загрузки, иначе 1.

## Что именно измеряется

Скорость HTTP-загрузки с выбранного сервера. Результат зависит от маршрута до сервера, его нагрузки и задержек, это не «скорость тарифа».

- Загрузки строго последовательные, каждая ждет полного тела ответа.
- Время загрузки включает разрешение имени, подключение, TLS и ожидание сервера.
- Средняя скорость: весь объем, деленный на суммарное время загрузок, а не среднее десяти скоростей. Иначе быстрая загрузка весит столько же, сколько медленная.
- 1 МБ = 1 000 000 байт, 1 Мбит = 1 000 000 бит.
- Загрузка засчитывается, только если сервер ответил 200 и отдал все байты из `Content-Length`. Оборванный ответ считается ошибкой, итог считается по успешным загрузкам.
- `--timeout` ограничивает каждую сетевую операцию, а не всю загрузку: медленная, но живая передача не обрывается.

## Как делалось

Контракт модуля (шапка `speedmeter.py`) до кода, затем код и тесты с Claude Code, затем независимое ревью второй моделью (GPT-6 Astra через Codex CLI). Ревью нашло реальные дефекты первой версии: оборванный ответ засчитывался как успешный, мегабайты были двоичными при подписи «Мбит/с», тест не отличал правильную формулу скорости от неправильной, частичный отказ давал код 0. Все исправлены, на каждый добавлен тест.

## Тесты

Поднимают локальный HTTP-сервер, интернет не нужен. Проверяют формулу скорости, 10 запросов по умолчанию, оборванный ответ, ответ 206, частичный и полный отказ, проверку аргументов.

```bash
python -m unittest -v
```
